# VS Code Keyboard Shortcuts (Windows - Default)

A curated list of the most commonly used Visual Studio Code keyboard shortcuts for Windows.

---

## General

| Shortcut | Action |
|:---|:---|
| `Ctrl + Shift + P` | Command Palette |
| `Ctrl + P` | Quick Open (Go to File) |
| `Ctrl + ,` | Open Settings |
| `Ctrl + K, Ctrl + S` | Open Keyboard Shortcuts |

## Editing Essentials

| Shortcut | Action |
|:---|:---|
| `Ctrl + X` | Cut line (empty selection) |
| `Ctrl + C` | Copy line (empty selection) |
| `Ctrl + D` | Add selection to next Find match |
| `Ctrl + Shift + K` | Delete line |
| `Alt + Up/Down` | Move line up/down |
| `Shift + Alt + Up/Down` | Copy line up/down |
| `Ctrl + /` | Toggle line comment |
| `Shift + Alt + A` | Toggle block comment |

## Navigation & Search

| Shortcut | Action |
|:---|:---|
| `Ctrl + F` | Find |
| `Ctrl + H` | Replace |
| `Ctrl + G` | Go to Line |
| `F12` | Go to Definition |
| `Alt + F12` | Peek Definition |
| `F2` | Rename Symbol |

## Multi-cursor & Selection

| Shortcut | Action |
|:---|:---|
| `Alt + Click` | Insert cursor |
| `Ctrl + Alt + Up/Down` | Insert cursor above/below |
| `Ctrl + Shift + L` | Select all occurrences of current selection |
| `Ctrl + F2` | Select all occurrences of current word |

## Editor Management

| Shortcut | Action |
|:---|:---|
| `Ctrl + N` | New File |
| `Ctrl + S` | Save |
| `Ctrl + W` | Close editor |
| `Ctrl + \` | Split editor |
| `Ctrl + 1 / 2 / 3` | Focus into 1st, 2nd, 3rd editor group |
| `Ctrl + B` | Toggle Sidebar visibility |

## Terminal

| Shortcut | Action |
|:---|:---|
| `` Ctrl + ` `` | Show integrated terminal |
| `` Ctrl + Shift + ` `` | Create new terminal |

---

## Customization

You can customize these shortcuts by pressing `Ctrl + K, Ctrl + S` or going to **File > Preferences > Keyboard Shortcuts**.
